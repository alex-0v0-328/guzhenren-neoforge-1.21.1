# 添加物品与实体

- 在对应 `ModItems.GuSpec`、相近物品/实体、语言 provider 找现有规格和命名；先区分一次性、需照顾、使用后消失与实体。领域约束读 AGENTS-reference §8，涉及存储/炼化时补 §5/§9。
- 跟随现有注册与服务入口接入行为，服务端执行写入和伤害；客户端只展示同步状态。明确 cooldown、所有者、死亡、加载、换维度和目标失效的状态归属，不预建六转及以后内容。
- 实体成套检查 EntityType、属性、出生谓词、群系 tag/modifier、客户端 renderer、模型/纹理/动画、语言与掉落；不默认增加刷怪蛋、驯服或繁殖。
- 模型权威源仅从 `C:/alex/code/blockbench/gzr-models/` 只读导入。保持模型/UV/动画边界，核验导出资源及纹理尺寸/Alpha；GeckoLib 用项目固定版本解析。自定义渲染不得绕过隐身、队伍可见或发光分支。
- provider 改动后运行 runData 并审阅生成差异。纯数学/规格用 L1，注册/解析用 L2，world/tick/伤害/NBT 用 L3；边界测试关注失败路径，不只验证开放空间中的成功动作。
- 代码数值与文档对应维护位置当场同步；开发理由放开发 wiki，玩家版本值放玩家快照。按根规则核对两张收工索引，列出准确的客户端验收事项。
